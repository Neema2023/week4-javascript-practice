
# Week 4: JavaScript Practice


This project contains my JavaScript practice exercises for Week 4. It helps me understand the basics of JavaScript through practical examples.

## Part 1: Control Flow and Loops
File: `part1-control-flow/day2.js`

Topics covered:
- Even or odd numbers
- Grade calculator
- Ticket pricing
- Day planner using switch
- Countdown
- Sum and average of numbers
- Finding numbers in arrays
- Using break and continue
- Multiplication table
- FizzBuzz and Kigali
- Printing a triangle using nested loops

## Part 2: Functions and Scope
File: `part2-functions-scope/day3.js`

Topics covered:
- Creating and calling functions
- Arrow functions
- Parameters and arguments
- Default and rest parameters
- Return values
- Temperature conversion
- Grade calculator
- Finding the maximum number
- Capitalizing words
- Counting vowels
- Checking palindromes
- Callbacks
- Closures and counters
- Discount calculator
- Scope, hoisting, and the Temporal Dead Zone
- Pure functions

## Technologies Used
- JavaScript
- Node.js
- Git and GitHub

## How to Run

Run Part 1:

```cmd
node part1-control-flow\day2.js
```

Run Part 2:

```cmd
node part2-functions-scope\day3.js
```

## What I Learned
I learned how to use conditions, loops, functions, callbacks, and closures, and how JavaScript variables behave in different scopes.
